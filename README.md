This mod was created by me (Baltazar) to make gravity anomalies more visible, since I ran into them too many times. I decided to customize the effect so they would be easier to recognize.

What I changed:

I added brown and yellow leaves to the mix, made the leaves bigger and made them fly higher into the sky.
The number of leaves has also been increased slightly.
The vacuum effect was also changed to include the colored leaves.
Notes:

There are 3 types of these anomalies (let's call them: small, average, and strong).
Idle anomalies: colored leaves are applied to each type.
Vacuum effect: the small ones don't have a vacuum effect and I didn't find the strong ones at all (I searched Jupiter, Zaton, etc.) so it remained at the default setting.
If you find an anomaly with the vacuum effect that contains only green leaves (these should be the strong ones), let me know and I'll check it.
Does it affect performance?

Yes, there are more and bigger leaves, but I'm not sure if it's noticeable
